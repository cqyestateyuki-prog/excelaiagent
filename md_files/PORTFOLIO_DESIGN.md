## 2. 项目概述 (Project Overview)

### 一句话描述
一个基于自然语言的 Excel 数据分析助手，让非技术用户通过对话式交互完成复杂的数据分析任务。

### 核心价值主张
- **降低技术门槛**: 用户无需编写代码，用自然语言提问即可获得专业级数据分析
- **智能预处理**: 自动处理复杂 Excel 结构（合并单元格、多级表头）
- **实时反馈**: 流式输出让用户实时看到分析进度
- **多模态交互**: 支持文本和语音两种输入方式

### 目标用户
- **数据分析师**: 快速探索数据，生成可视化报告
- **业务人员**: 无需学习 Excel 高级功能，直接提问获取洞察
- **学生/研究者**: 处理实验数据，快速生成统计结果

## 3. 设计挑战 (Design Challenges)

### 问题陈述
传统数据分析工具（如 Excel、Python）存在以下痛点：
1. **学习曲线陡峭**: 需要掌握公式、函数或编程语言
2. **交互复杂**: 多步骤操作，容易出错
3. **反馈延迟**: 无法实时看到分析进度
4. **结果理解困难**: 代码输出对非技术用户不友好

### 设计目标
- ✅ **零学习成本**: 自然语言交互，无需培训
- ✅ **即时反馈**: 实时流式输出，减少等待焦虑
- ✅ **结果可视化**: 自动生成图表，直观展示数据洞察
- ✅ **可追溯性**: 清晰展示使用了哪些数据列，增强信任度

## 4. 用户研究 (User Research)

### 用户画像

#### 主要用户：数据分析师 Sarah
- **年龄**: 28-35 岁
- **职业**: 数据分析师 / 业务分析师
- **痛点**:
  - 需要快速处理多个 Excel 文件
  - 重复性分析任务占用大量时间
  - 希望快速生成可视化报告
- **使用场景**: 
  - 每周需要分析销售数据趋势
  - 对比不同地区的业绩表现
  - 生成月度分析报告

#### 次要用户：业务经理 David
- **年龄**: 35-45 岁
- **职业**: 产品经理 / 业务经理
- **痛点**:
  - 不熟悉 Excel 高级功能
  - 需要快速获取数据洞察，但不想学习编程
- **使用场景**:
  - 查看产品销量排名
  - 分析用户增长趋势
  - 快速回答老板的数据问题

### 用户旅程地图 (User Journey Map)

```
1. 上传文件阶段
   - 痛点: 不确定文件格式是否支持
   - 设计: 拖拽上传 + 实时状态反馈

2. 提问阶段
   - 痛点: 不知道如何提问才能得到好结果
   - 设计: 示例问题提示 + 语音输入降低输入成本

3. 等待分析阶段
   - 痛点: 不知道系统在做什么，容易焦虑
   - 设计: 分阶段进度提示（代码生成 → 执行 → 总结）

4. 查看结果阶段
   - 痛点: 结果分散，难以理解
   - 设计: 结构化展示（代码、输出、总结、图表、追溯）

5. 后续操作阶段
   - 痛点: 想基于结果继续提问
   - 设计: 保留历史结果，支持多轮对话（未来功能）
```

## 6. 用户流程设计 (User Flow)

### 主要流程：数据分析

```
开始
  ↓
[上传 Excel 文件]
  ↓ (自动预处理 + 索引)
[输入自然语言问题]
  ↓
[点击 "Run Analysis"]
  ↓
[系统生成分析计划] → 显示进度
  ↓
[生成 Python 代码] → 流式输出到 UI
  ↓
[执行代码] → 流式输出执行结果
  ↓
[生成可视化图表] → 自动渲染
  ↓
[生成分析总结] → AI 总结关键发现
  ↓
[显示数据追溯] → 展示使用的数据列
  ↓
结束（用户可继续提问或清除结果）
```

### 次要流程：语音输入

```
开始
  ↓
[点击 "Start Recording"]
  ↓
[浏览器录音] → 实时音频流
  ↓
[WebSocket 传输到后端]
  ↓
[OpenAI Realtime API 转写]
  ↓
[显示转写结果] → 带时间戳
  ↓
[自动填入查询框]
  ↓
[用户确认后点击分析]
  ↓
进入主要流程
```

## 7. 交互设计 (Interaction Design)

### 关键交互点

#### 1. 文件上传
- **交互方式**: 拖拽 + 点击上传
- **反馈机制**: 
  - 上传中: 显示进度条
  - 处理中: "Preprocessing..." → "Indexing..."
  - 完成: "Ready" 状态
- **错误处理**: 文件格式错误提示，支持重试

#### 2. 流式输出 (SSE)
- **交互方式**: 实时追加内容，无需刷新
- **视觉反馈**: 
  - 代码区域: 逐行显示，语法高亮（可选）
  - 输出区域: 实时追加执行结果
  - 总结区域: 逐段显示，模拟思考过程
- **加载状态**: 分阶段加载指示器

#### 3. 图表展示
- **交互方式**: iframe 嵌入 Plotly 交互式图表
- **视觉层次**: 
  - 图表标题清晰
  - 多个图表垂直排列
  - 支持缩放、悬停等交互

#### 4. 语音输入
- **交互方式**: 点击开始/停止录音
- **反馈机制**:
  - 录音中: 按钮高亮 + 动画效果
  - 转写中: 显示 "Transcribing..."
  - 完成: 显示转写文本 + 时间戳

## 8. 视觉设计 (Visual Design)

### 设计系统

#### 色彩方案
- **主背景**: 纯白色 (`#ffffff`) - 简洁清晰，减少视觉干扰
- **卡片背景**: 浅灰色 (`#f5f5f5`) - 左侧面板卡片使用灰色，形成层次
- **顶部区域**: 更浅灰色 (`#fafafa`) - header 和 features section
- **主色调**: Excel 绿色系
  - 主绿色: `#107C41` - Excel 品牌绿色（标题、按钮、强调）
  - 深绿色: `#0D5D2E` - 深色变体（正文、副标题）
  - 浅绿色: `#f0f7f4` - 浅色变体（悬停状态）
- **文字颜色**: 
  - 主文字: `#107C41` (Excel 绿色)
  - 正文文字: `#0D5D2E` (深绿色)
  - 次要文字: `#666666` (中灰色)
- **边框**: `#e0e0e0` (浅灰色，统一使用)

#### Typography
- **字体**: System Font Stack (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`)
- **主标题**: 2.4em, 字间距 0.05em
- **核心操作标题**: 22px (唯一特殊大小，突出核心功能)
- **标准标题**: 16px (统一大小)
- **正文**: 14px-17px
- **等宽字体**: `'Courier New', monospace` (代码块)

#### 间距系统
- **容器内边距**: 20px-30px
- **卡片内边距**: 12px (统一)
- **元素间距**: 8px, 12px, 14px, 15px, 16px, 20px
- **标题下边距**: 8px-12px

#### 组件设计

##### 按钮
- **主要按钮 (Run Analysis)**: Excel 绿色纯色背景 (`#107C41`)，白色图标，悬停变深
- **次要按钮 (Clear Results)**: 透明背景，灰色图标 (`#333333`)
- **语音按钮**: 默认浅灰背景绿色图标，录音中红色背景白色图标，脉冲动画
- **图标按钮**: 内嵌在输入框内，无文字标签

##### 输入框
- **文本输入**: 白色背景，浅灰边框，聚焦时绿色边框 + 绿色阴影
- **文件上传**: 灰色卡片背景，白色虚线边框区域，悬停时绿色边框

##### 卡片
- **左侧面板卡片**: 灰色背景 (`#f5f5f5`)，10px 圆角，12px 内边距，无阴影
- **结果卡片**: 更浅灰色背景 (`#fafafa`)，8px 圆角，16px 内边距，无阴影
- **统一设计**: 所有卡片使用 `1px solid #e0e0e0` 边框，无阴影

##### 加载状态
- **"..." 动画**: 标题后内联显示，`.` → `..` → `...` 循环动画
- **流式输出**: 逐字/逐行显示效果，实时追加内容

##### 布局
- **左右分栏**: 1:3 比例 (Grid: `1fr 3fr`)
- **全宽显示**: 无最大宽度限制，无左右留白
- **无圆角容器**: 全屏显示，`border-radius: 0`

### 响应式设计
- **桌面端**: 左右分栏布局（输入区 1/4 + 结果区 3/4）
- **平板端**: 可考虑上下堆叠（未来优化）
- **移动端**: 单列布局，结果区可折叠（未来优化）

## 10. 设计决策 (Design Decisions)

### 决策 1: 白色主题 + Excel 绿色
**原因**:
- 白色背景简洁清晰，减少视觉干扰，符合现代 Web 应用趋势
- Excel 绿色作为主色调，与产品定位（Excel 数据分析）高度契合
- 左侧面板卡片使用灰色背景，形成清晰的视觉层次
- 代码块使用深色背景，保证代码可读性

### 决策 2: 左右分栏布局
**原因**:
- 输入和输出分离，逻辑清晰
- 结果区可以独立滚动，不影响输入
- 适合桌面端大屏幕使用

### 决策 3: 流式输出而非一次性显示
**原因**:
- 减少用户等待焦虑
- 让用户了解系统工作过程
- 增强交互感和参与感

### 决策 4: 结构化结果展示
**原因**:
- 不同用户关注不同信息（技术用户看代码，业务用户看总结）
- 分层展示让信息更易消化
- 支持用户按需查看

### 决策 5: 语音输入作为可选功能
**原因**:
- 降低输入成本，提高效率
- 但保持文本输入为主，避免过度依赖语音
- 语音转写结果可编辑，保证准确性

## 11. 可用性测试 (Usability Testing)

### 测试场景
1. **首次使用**: 新用户能否在 5 分钟内完成第一次分析？
2. **复杂查询**: 用户能否用自然语言表达复杂的数据分析需求？
3. **结果理解**: 用户能否快速理解分析结果和图表？

### 测试指标
- **任务完成率**: 90%+ 用户能成功完成分析
- **时间效率**: 平均分析时间 < 2 分钟
- **用户满意度**: NPS 评分 > 50

### 改进迭代
- **V1**: 基础功能实现
- **V2**: 添加语音输入，提升输入效率
- **V3**: 优化图表生成逻辑，减少不必要图表
- **V4**: 添加数据追溯，增强结果可信度
- **V5**: 语言自适应（图表标签、追溯报告）

## 12. 技术实现亮点 (Technical Highlights)

### 前端技术
- **SSE (Server-Sent Events)**: 实现实时流式输出
- **WebSocket**: 支持语音输入实时传输
- **原生 JavaScript**: 无框架依赖，性能优异
- **响应式 CSS**: 纯 CSS 实现复杂布局和动画

### 后端技术
- **Python**: 主要编程语言
- **Flask + Socket.IO**: 轻量级 Web 框架
- **Jupyter Kernel**: 隔离的 Python 代码执行环境
- **Pandas + Plotly**: 数据处理和可视化库
- **OpenAI API**: 代码生成、总结、语音转写

### 设计亮点
- **单页面应用**: 无需页面跳转，流畅体验
- **模块化组件**: 易于维护和扩展
- **错误处理**: 友好的错误提示和恢复机制

## 14. 反思与学习 (Reflection & Learnings)

### 成功之处
1. **用户中心设计**: 从用户痛点出发，而非技术实现
2. **渐进式展示**: 流式输出让复杂过程变得可理解
3. **多模态交互**: 文本 + 语音，满足不同用户习惯

### 改进空间
1. **移动端适配**: 当前主要针对桌面端，移动端体验需优化
2. **多轮对话**: 支持基于前一个结果的继续提问
3. **结果导出**: 支持导出分析报告（PDF/HTML）
4. **协作功能**: 支持分享分析结果给团队成员

### 设计思考
- **简化 vs 功能完整**: 如何在保持简单的同时提供强大功能？
- **实时反馈 vs 性能**: 流式输出如何平衡用户体验和服务器负载？
- **AI 透明度**: 如何让用户理解 AI 的工作过程，增强信任？

## 📝 作品集文案模板

### 项目简介（100-150 字）
> Excel AI Agent 是一个基于自然语言的智能数据分析助手，让用户无需编写代码即可完成复杂的数据分析任务。通过 AI 技术，系统能够理解用户的自然语言问题，自动生成 Python 分析代码，执行分析并生成可视化图表。项目采用简洁的白色主题设计，以 Excel 绿色作为主色调，支持实时流式输出和语音输入，为数据分析师和业务人员提供高效、直观的数据分析体验。

### 设计挑战（50-80 字）
> 如何让非技术用户也能轻松完成复杂的数据分析？如何让 AI 的工作过程透明可理解？如何平衡功能完整性和使用 simplicity？这些是我们在设计 Excel AI Agent 时面临的核心挑战。

### 解决方案（80-120 字）
> 我们采用自然语言交互降低使用门槛，通过流式输出让用户实时了解分析进度，用结构化展示让结果更易理解。支持文本和语音两种输入方式，自动生成交互式图表，并提供数据追溯功能增强结果可信度。整个设计以用户为中心，追求 simplicity 而不失功能强大。
