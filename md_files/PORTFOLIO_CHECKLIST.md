### 4. 快速文案模板 (Quick Copy Templates)

#### 项目简介（100-150 字）
```
Excel AI Agent 是一个基于自然语言的智能数据分析助手，让用户无需编写代码即可完成复杂的数据分析任务。通过 AI 技术，系统能够理解用户的自然语言问题，自动生成 Python 分析代码，执行分析并生成可视化图表。项目采用深色主题设计，支持实时流式输出和语音输入，为数据分析师和业务人员提供高效、直观的数据分析体验。
```

#### 设计挑战（50-80 字）
```
如何让非技术用户也能轻松完成复杂的数据分析？如何让 AI 的工作过程透明可理解？如何平衡功能完整性和使用 simplicity？这些是我们在设计 Excel AI Agent 时面临的核心挑战。
```

#### 解决方案（80-120 字）
```
我们采用自然语言交互降低使用门槛，通过流式输出让用户实时了解分析进度，用结构化展示让结果更易理解。支持文本和语音两种输入方式，自动生成交互式图表，并提供数据追溯功能增强结果可信度。整个设计以用户为中心，追求 simplicity 而不失功能强大。
```

#### 设计决策示例（50-80 字/个）
```
决策：采用深色主题
原因：数据分析工具通常需要长时间使用，深色主题减少眼疲劳，符合 AI/科技产品的视觉趋势，代码显示在深色背景上更清晰。
效果：用户反馈界面更专业，长时间使用不易疲劳。
```
