# Excel AI Agent - 设计系统规范

## 📐 设计原则

### 核心理念
- **简洁清晰**: 白色背景，减少视觉干扰
- **Excel 绿色主题**: 使用 Excel 品牌绿色作为主色调
- **信息层次**: 通过卡片、间距、字体大小建立清晰的信息层级
- **一致性**: 统一的颜色、字体、间距、圆角、边框样式

---

## 🎨 色彩系统

### 主色调 - Excel 绿色
- **主绿色**: `#107C41` - Excel 品牌绿色
  - 用于：标题、按钮、强调文字、边框高亮
- **深绿色**: `#0D5D2E` - 深色变体
  - 用于：副标题、正文文字、按钮悬停状态
- **浅绿色**: `#f0f7f4` - 浅色变体
  - 用于：卡片悬停背景、功能卡片悬停

### 背景色
- **主背景**: `#ffffff` - 纯白色
  - 用于：body、container、左右面板、输入框、文件列表项
- **卡片背景**: `#f5f5f5` - 浅灰色
  - 用于：左侧面板卡片（file-upload、input-section、step-label、file-list）
- **顶部区域**: `#fafafa` - 更浅的灰色
  - 用于：header、features-section、result-item

### 边框色
- **标准边框**: `#e0e0e0` - 浅灰色
  - 用于：所有卡片、输入框、文件列表的边框
- **虚线边框**: `#d0d0d0` - 更浅的灰色
  - 用于：文件上传区域的虚线边框
- **聚焦边框**: `#107C41` - Excel 绿色
  - 用于：输入框聚焦状态

### 文字颜色
- **主文字**: `#107C41` - Excel 绿色
  - 用于：标题、链接、强调文字
- **正文文字**: `#0D5D2E` - 深绿色
  - 用于：正文、输入框文字
- **次要文字**: `#666666` - 中灰色
  - 用于：状态文字、辅助信息
- **占位符**: `#9ca3af` - 浅灰色
  - 用于：输入框占位符

### 特殊用途颜色
- **代码块背景**: `#2d2d2d` - 深色背景
- **代码块文字**: `#f8f8f2` - 浅色文字
- **录音状态**: `#dc2626` - 红色
- **禁用状态**: `#a5d6a7` - 浅绿色

## 📝 字体系统

### 字体族
- **系统字体栈**: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`
- **等宽字体**: `'Courier New', monospace`
  - 用于：代码块、数据输出

### 字体大小
- **主标题 (h1)**: `2.4em` - 48px (约)
  - 用于：页面主标题
- **核心操作标题**: `22px` / `1.375em`
  - 用于："Ask Your Question" 标题（唯一特殊大小）
- **标准标题**: `16px` / `1em`
  - 用于：step-label、file-list-title、section-title、details-type-title
- **正文**: `14px-17px` / `0.875em-1.0625em`
  - 用于：输入框、正文内容
- **小字**: `11px-13px` / `0.6875em-0.8125em`
  - 用于：标签、状态文字、占位符

### 字重
- **粗体**: `700` / `bold`
  - 用于：核心操作标题
- **半粗**: `600` / `semibold`
  - 用于：标准标题、按钮
- **中等**: `500` / `medium`
  - 用于：功能卡片标题、上传标签
- **常规**: `400` / `normal`
  - 用于：正文

### 字间距
- **主标题**: `0.05em`
- **按钮**: `0.02em`

## 📏 间距系统

### 内边距 (Padding)
- **容器内边距**: `20px-30px`
  - 用于：左右面板、header
- **卡片内边距**: `12px`
  - 用于：file-upload、input-section、result-item
- **输入框内边距**: `10px-15px`
  - 用于：文本输入框、API key 输入框
- **标题内边距**: `10px 14px`
  - 用于：step-label

### 外边距 (Margin)
- **元素间距**: `8px, 12px, 14px, 15px, 16px, 20px`
  - 用于：卡片之间、元素之间
- **标题下边距**: `8px-12px`
  - 用于：所有标题的 margin-bottom

### Gap (Flex/Grid)
- **面板间距**: `14px`
  - 用于：left-panel、right-panel 的 flex gap
- **功能卡片间距**: `12px`
  - 用于：features-grid

## 🔲 边框与圆角

### 边框
- **标准边框**: `1px solid #e0e0e0`
  - 用于：所有卡片、输入框
- **强调边框**: `2px solid #107C41`
  - 用于：features-section 底部绿线
- **虚线边框**: `1px dashed #d0d0d0`
  - 用于：文件上传区域

### 圆角
- **大圆角**: `10px`
  - 用于：主要卡片（file-upload、input-section）
- **中圆角**: `8px`
  - 用于：输入框、按钮、step-label、result-item
- **小圆角**: `6px`
  - 用于：功能卡片、代码块、数据块

---

## 📐 布局系统

### 整体布局
- **布局方式**: CSS Grid
- **左右比例**: `1fr : 3fr` (1:3)
- **全宽显示**: `max-width: 100%`, `margin: 0`
- **无圆角**: `border-radius: 0` (全屏显示)

### 面板结构
```
Header + Features Section (顶部)
├── Left Panel (1/4 宽度)
│   ├── API Key Input
│   ├── File Upload Card (灰色背景)
│   ├── Indexed Files (灰色背景)
│   └── Step Labels (灰色背景)
└── Right Panel (3/4 宽度)
    └── Ask Your Question Card (灰色背景)
        └── Results Section
```

### 响应式
- **桌面端**: 左右分栏 (1:3)
- **滚动**: 左侧面板独立滚动，右侧面板可见

## 🧩 组件规范

### 按钮

#### 主要按钮 (Run Analysis)
- **背景**: `#107C41` (纯色，无渐变)
- **文字**: `#ffffff`
- **悬停**: `#0D5D2E`
- **禁用**: `#a5d6a7`
- **尺寸**: 图标按钮，内嵌在输入框内
- **图标**: 向上箭头 (↑)

#### 次要按钮 (Clear Results)
- **背景**: 透明
- **图标颜色**: `#333333`
- **悬停**: `#000000`
- **尺寸**: 图标按钮，内嵌在输入框内
- **图标**: 垃圾桶 (🗑️)

#### 语音按钮
- **默认**: 浅灰色背景，绿色图标
- **录音中**: 红色背景 (`#dc2626`)，白色图标，脉冲动画
- **尺寸**: 图标按钮，内嵌在输入框内

### 输入框

#### 文本输入框
- **背景**: `#ffffff`
- **边框**: `1px solid #e0e0e0`
- **圆角**: `8px`
- **内边距**: `12px-15px`
- **聚焦**: 边框变为 `#107C41`，添加 `box-shadow: 0 0 0 2px rgba(16,124,65,0.1)`

#### 文本域 (Query Textarea)
- **最小高度**: `200px`
- **内边距**: `12px 160px 12px 12px` (右侧留出按钮空间)
- **其他**: 同文本输入框

### 卡片

#### 左侧面板卡片
- **背景**: `#f5f5f5` (灰色)
- **边框**: `1px solid #e0e0e0`
- **圆角**: `10px`
- **内边距**: `12px`
- **无阴影**: `box-shadow: none`

#### 结果卡片
- **背景**: `#fafafa` (更浅的灰色)
- **边框**: `1px solid #e0e0e0`
- **圆角**: `8px`
- **内边距**: `16px`
- **无阴影**: `box-shadow: none`

### 文件列表

#### 文件列表容器
- **背景**: `#f5f5f5` (灰色)
- **边框**: `1px solid #e0e0e0`
- **圆角**: `8px`
- **最大高度**: `180px`
- **滚动条**: 自定义样式

#### 文件项
- **背景**: `#ffffff` (白色)
- **边框**: `1px solid #e0e0e0` (底部边框)
- **内边距**: `8px 12px`
- **最后一项**: 无底部边框

### 加载状态

#### "..." 动画
- **位置**: 标题后内联显示
- **动画**: `.` → `..` → `...` 循环
- **时长**: `1.5s`
- **使用场景**: Analysis summary、Analysis process、Generated code、Execution output、Charts

## 🎯 交互状态

### 悬停 (Hover)
- **功能卡片**: 背景变为 `#f0f7f4`，边框变为 `#107C41`
- **上传标签**: 背景变为 `#f0f7f4`，边框变为 `#107C41`，轻微上移
- **按钮**: 背景变深，轻微上移
- **折叠标题**: 透明度变为 `0.8`

### 聚焦 (Focus)
- **输入框**: 边框变为 `#107C41`，添加绿色阴影
- **移除默认轮廓**: `outline: none`

### 禁用 (Disabled)
- **按钮**: 背景变为 `#a5d6a7`，不可点击

### 活动状态 (Active)
- **录音中**: 红色背景，脉冲动画
- **分析中**: "Run Analysis" 按钮变为 "Stop Analysis" (红色 × 图标)

## 📱 响应式设计

### 当前实现
- **桌面端优先**: 主要针对桌面端设计
- **固定比例**: 左右面板 1:3 比例
- **全宽显示**: 无最大宽度限制

### 未来优化
- **平板端**: 可考虑上下堆叠
- **移动端**: 单列布局，结果区可折叠

## ♿ 无障碍设计

### 对比度
- **文字对比度**: 确保 WCAG 4.5:1 标准
- **绿色文字**: `#107C41` 在白色背景上符合标准
- **深绿色文字**: `#0D5D2E` 在白色背景上符合标准

### 交互
- **键盘导航**: 支持 Tab 键导航
- **焦点指示**: 清晰的聚焦状态
- **按钮标签**: 所有按钮都有 title 属性
